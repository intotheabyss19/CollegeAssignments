## Software and Environment
Recommended: Python 3.10+. VS Code.
Suggested packages: pip install cryptography sympy ecdsa

# LIST OF EXPERIMENTS:
1. Write a program to implement Data Encryption Standard (DES)
2. Write a program to implement Advanced Encryption Standard (AES).
3. RSA Public-Key Encryption and Decryption
4. Generate and verify a digital signature and demonstrate rejection of a modified message using RSA-PSS (Probabilistic Signature Scheme).
5. Write a program to implement Diffie-Hellman Key exchange algorithm.
6. Write a program to break the mono alphabetic cipher.
7. Write a program to break a Vigenère (poly alphabetic) cipher using frequency analysis and key-length estimation
8. Write a program to implement point addition, point doubling and scalar multiplication on Elliptic-Curve Arithmetic over a Prime Field.
9. Write a program to implement Elliptic Curve Diffie-Hellman (ECDH) Key agreement algorithm.
10. Write a program to implement Elliptic Curve Digital Signature Authentication (ECDSA) algorithm.
11. Write a program to implement Bilinear Pairing using a algebraic pairing model.
12. Write a program to implement Identity-Based Encryption (IBE) and demonstrate the conceptual IBE workflow: Setup, Extract, Encrypt and Decrypt.
